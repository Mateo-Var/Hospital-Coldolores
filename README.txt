PROYECTO COLDOLORES - PANEL DE MONITOREO

Archivos incluidos:
- index.html
- styles.css
- script.js

Cómo abrirlo en Visual Studio Code:
1. Descomprime la carpeta si la descargaste comprimida.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo index.html.
4. Si tienes la extensión Live Server, da clic derecho sobre index.html y luego en "Open with Live Server".
5. También puedes abrir index.html directamente en el navegador.

Qué puedes editar:
- Textos y estructura: index.html
- Colores, layout y responsive: styles.css
- Interacciones como menú móvil y modo oscuro: script.js
